The technology stack

Built to work together.

A practical deployment workflow connecting application code, container images, automation, and orchestration.

01 / AUTOMATION ↗

Jenkins CI/CD

Automates the pipeline for checking out source code, running tests, building images, publishing them, and deploying the application.

02 / CONTAINERS □

Docker

Packages the Flask application and its dependencies into a container image that can be distributed and deployed consistently.

03 / ORCHESTRATION ⌘

Kubernetes

Manages application Pods, desired replicas, health probes, and network access through Kubernetes resources.

04 / APPLICATION ⌁

Flask & Python

Serves the web interface and exposes a health endpoint used to check whether the application is responding.

05 / SOURCE CONTROL ⌥

Git & GitHub

Stores the application source code, Kubernetes manifests, Docker configuration, and Jenkinsfile for version-controlled delivery.

06 / ENVIRONMENT ◎

MicroK8s

Provides the Kubernetes environment used to run and manage the application's workloads during development and testing.
